## Interfaces

Track.mix: optional TrackMix; Project.masterDb: optional number. normalizeMix returns a complete finite settings object. EQ coefficients and graph response share sample-rate-dependent sections. Mixer owns nodes by track ID, sources remain cached by sample ID. createEngine exposes meter/spectrum/listen accessors without persistence writes. Native and WASM Dragonfly use the same wrapper exports.
