## Constraints and decisions

- Models and instrument packs are fetched from Hugging Face through `VITE_MODELS_BASE_URL` (`src/store/modelsBase.ts`); packs are listed in `manifest.json` (`id`, `label`, `requires`, `files`, `totalBytes`).
- The server already sends COOP `same-origin` and COEP `require-corp` headers, so WASM threads work where the browser allows them.
- Cloud key: the user pasted a Stability key into a chat during testing. It is stored nowhere in this repository. Rotate it.
- Secrets live in TokenCrypt (`tokencrypt status`, `tokencrypt run --with <name> -- <command>`); never write a secret into a file or ask for one in chat.
- Workers and reviewers run on Sonnet; the coordinator does not write implementation code. The user asked for no design drafts and no review rounds in this stage.
