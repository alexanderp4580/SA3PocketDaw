State as of 2026-10-07 (instrument integration). Wave 4 was stopped by the user; the app is hosted for phone testing. This document lists what is done, what is open and a working log that the active worker appends to after every milestone, so a new session can continue at any point.

## What this is

Phone-first browser DAW proof of concept. SA3 (Stable Audio 3) generates a sample or an automatically tuned instrument on-device; a piano roll plays it chromatically. Design: `docs/design.md`. Project rules: `AGENTS.md`. The layout follows the PocketDaw mockups (`/home/deck/SketchBook/Projects/PocketDaw/docs/mockups/`); the user said not to change it. Style tokens come from AstraCamillaGui (`/home/deck/SketchBook/Projects/AstraMoode/AstraCamillaGui/client`).

Confirmed decisions: two generation paths, Sample (one-shot sampler) and Instrument (single-note hybrid resynthesis with automatic tuning); one looping pattern per track; single generation auto-kept; hand-drawn melodies only; models Small SFX, Small Music and Medium, each installed with one Download button into Cache Storage and removable (per model, all models, all app data); LAN self-signed HTTPS hosting from the Deck; mixer later.

## Hosting for testing

`node server/serve.mjs` serves `dist/` and `/models/` on https://0.0.0.0:8443 (self-signed cert from `scripts/make-cert.sh`, SANs include 192.168.8.191 and 192.168.8.226) and http://127.0.0.1:8082. Link used on the phone: https://192.168.8.191:8443/. Start it detached with `setsid nohup node server/serve.mjs > /tmp/sa3daw-server.log 2>&1 &`; stop it by killing the pid shown by `ss -ltnp | grep 8443` (do not use `pkill -f server/serve.mjs` from a shell command that contains that text). After `npm run build` the running server serves the new files without a restart. `npm run manifest` must be re-run after model files change.

## Known limits and open choices

- The app uses Small Music's shared text encoder for Small SFX. The SFX model has a different padding embedding; a patched SFX encoder (212 MB) exists in `models/small-sfx/onnx/` but is not used by the app. Decide after listening to SFX output.
- Pack file sets: encoder 249,129,463 bytes; small-music 433,426,045; medium 2,044,371,283; small-sfx 675,147,009 in 21 files on disk (the manifest lists only its dit, decoder and number-conditioner files).
- Ports: HTTPS 8443; HTTP defaults to 8082 because Steam and another process hold 8080 and 8081.
- Firewall: firewalld runs on the Deck. Whether LAN clients reach 8443 is to check; do not change firewall settings without the user.
- Licences: the model weights keep Stability AI Community License (and Gemma terms for the T5Gemma encoder). Redistribution by hosting them for others was not reviewed.
- The Mix screen is a disabled nav item.
- Nothing is committed. The repo was initialised with `git init` only.
